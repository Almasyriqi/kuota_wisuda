# Dokumentasi Kuota Wisuda

Indeks dokumentasi teknis aplikasi **Kuota Wisuda**. Seluruh isi dokumen di
folder ini ditulis berdasarkan analisis kode sumber yang berjalan saat ini
(bukan spekulasi), termasuk mendokumentasikan fitur yang belum lengkap agar
menjadi backlog yang jelas.

| Dokumen | Isi |
|---|---|
| [SRS.md](./SRS.md) | Software Requirement Specification — kebutuhan fungsional, non-fungsional, aturan bisnis, dan known gaps |
| [FEATURES.md](./FEATURES.md) | Daftar fitur per modul beserta status implementasinya |
| [FLOWMAP.md](./FLOWMAP.md) | Flow map (diagram Mermaid) untuk navigasi, proses bisnis, dan ER diagram |

Untuk cara instalasi dan menjalankan project, lihat [README.md](../README.md)
di root repository.
